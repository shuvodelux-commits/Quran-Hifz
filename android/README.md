# Android platform scaffold

This directory follows the Flutter 3.47.2 Android template (AGP 9.1.0, Kotlin 2.4.0, Gradle 9.3.1) and includes the `just_audio_background` MediaSession service/receiver manifest wiring.

The Gradle wrapper JAR is generated by Flutter/Gradle and is intentionally not fabricated here. On a workstation with Flutter 3.47.2, run `flutter create --platforms=android .` if `android/gradle/wrapper/gradle-wrapper.jar` and the platform wrapper scripts are not already present, then preserve this manifest and application configuration. Afterward run `flutter pub get` and `flutter build apk --debug`.
