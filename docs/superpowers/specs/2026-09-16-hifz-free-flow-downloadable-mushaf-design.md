# Hifz Free Flow and Downloadable Mushaf Design

Date: 2026-09-16
Status: Awaiting final user review

## Goal

Make the bundled Hifz reader resemble a clean IndoPak Mushaf while remaining freely scalable, and retain Fixed Mushaf as an optional offline download made from pre-rendered, licensed Mushaf pages.

## Reader modes

### Free Flow

Free Flow is bundled, available offline immediately, and remains the default. It uses the selected Hifz Quran font, font size, and line spacing independently of global Quran typography.

The layout is composed as visual Quran lines rather than ayah cards or isolated word boxes:

- right-to-left words share one baseline;
- normal compact word gaps are used, with only small capped expansion when a nearly full row can be justified;
- every visual line has a subtle bottom separator;
- incomplete lines remain naturally right-aligned instead of stretching large gaps across the width;
- no whole-ayah background or playback box is rendered;
- tapping a word keeps word meaning/audio and highlights only that word;
- tapping blank page space toggles controls.

Ayah markers are inline baseline-aligned ornaments. Their ornament, numeral, hit target, and row measurement all scale from the selected Hifz font size. The numeral remains centered inside the ornament and must not use a fixed pixel size.

### Bismillah

Every applicable Surah starts with a large, centered standalone Bismillah using the dedicated PDMS Saleem Quran rendering. It is separated from the first Quran line and never stretched or left-aligned.

Al-Fatihah's Bismillah ayah is promoted to this standalone header and removed from the normal word row so it is not duplicated. At-Tawbah remains the canonical exception and has no inserted Bismillah.

### Downloaded Fixed Mushaf

Fixed Mushaf is not generated by shrinking live word widgets. It is an optional catalog of licensed, pre-rendered page packs. The first supported pack is IndoPak; additional packs can be added without changing the app binary.

A source PDF is converted before distribution, never on the phone. Each downloadable pack contains:

- a versioned JSON manifest;
- one WebP image per Mushaf page;
- page count and page-to-Surah/Juz metadata;
- file sizes and SHA-256 checksums;
- attribution and license fields;
- optional word-coordinate metadata for word tapping and highlighting.

WebP page images are preferred over rendering PDF pages at runtime because they give predictable typography, fast page opening, low memory use, and simple adjacent-page prefetching. Packs are distributed as ZIP archives and extracted atomically after checksum verification.

The viewer uses paged navigation, pinch zoom, double-tap zoom, and preloads the previous and next page. If a pack has no word-coordinate metadata, it is explicitly reading-only: page navigation and zoom work, but fake or inaccurate word taps are not offered.

## Downloads and storage

The Mushaf catalog shows pack name, script/style, preview, download size, license/attribution, installed version, and Download/Update/Delete actions.

Downloads support visible progress, cancellation, retry, temporary partial files, checksum verification, and safe cleanup after failure. A pack becomes selectable only after the archive is verified and completely extracted. Removing a pack deletes only that pack; Free Flow and Quran text data are unaffected.

Previously saved `fixedMushaf` preference values fall back to Free Flow whenever the selected page pack is unavailable.

## Initial scope

1. Refine and verify Free Flow against the supplied visual reference.
2. Replace the existing shrinking Fixed Mushaf renderer with the pack-backed viewer and catalog.
3. Support one IndoPak pack end to end once a licensed PDF/page source is supplied.
4. Keep the catalog extensible to five packs; do not publish unlicensed or guessed resources.
5. Add further popular packs only after their files, redistribution terms, names, and checksums are confirmed.

## Testing and acceptance

- Golden/widget coverage verifies centered Bismillah, compact RTL word gaps, separators, baseline-aligned scalable markers, and no overflow at minimum/maximum font and system scales.
- Interaction tests verify word tap versus blank-space tap and word-only playback highlighting.
- Preference tests verify Hifz typography independence and fallback from unavailable fixed packs.
- Download tests cover success, cancellation, checksum failure, interrupted extraction, update, and deletion.
- Viewer tests cover page order, zoom, prefetch, missing pages, and optional coordinate overlays.
- Final acceptance includes screenshots and interaction checks on the connected Android device.

## Required content decision

Implementation may build the pack infrastructure without copyrighted page assets. A distributable Fixed Mushaf cannot be shipped until the user supplies or approves a source whose redistribution license permits inclusion or download.
